# 智购洞察 SmartShop Insight

网络应用架构课程设计：一个带用户行为采集、销售分析和推荐功能的三角色电商系统。

## 运行

```bash
python3 app.py --host 127.0.0.1 --port 18080
```

打开 `http://127.0.0.1:18080`。

## 功能

- 游客浏览、搜索商品；用户注册、登录、购物车和模拟付款
- 销售人员管理商品与分类，查看订单、浏览及操作日志
- 管理员管理销售账号并重置密码
- 登录、IP、浏览时长、购买和管理操作日志采集
- 用户画像、销售排行、日/周/月趋势、线性趋势预测、异常与库存预警
- 共购关联推荐、基于用户相似度的协同过滤推荐及冷启动降级
- CSV 数据导出、响应式移动端界面
